# Changelog

All notable changes to the STAR Music client will be documented in this file.

## [v1.0.0] - 2026-11-10

### Added
- **Glassmorphic Desktop UI**: Frameless, transparent, draggable OS-level mini player with native window controls and smooth transitions.
- **Complete Light Mode Overhaul**: Fully refactored high-contrast light theme across TopBar, OfflineView, BottomPlayer, Modals, and Player sliders with zero contrast bugs.
- **Guest Theme Lockdown**: Restricts visual styling and theme switching on guest devices to preserve host-controlled acoustic ambience.
- **Production .exe Packaging**: Configured `electron-builder` distribution pipeline with relative asset routing, hash router compatibility, and startup route auto-reset to `/`.
- **Zero-Login Ecosystem**: Hardware-locked cryptographic 256-bit signatures.
- **STAR Sync (Host/Guest)**: Real-time multi-device playback synchronization via pairing codes and LAN integration.
- **Offline High-Fidelity Engine**: 320kbps local caching with persistent ID3 artwork.
