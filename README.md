# 🌟 STAR Music App
*Multi-Platform Distributed Audio Suite // Zero-Login Ecosystem*

---

### Overview
**STAR Music** is an advanced, high-fidelity music streaming and offline listening client engineered with a cutting-edge Web Audio API graph and distributed real-time multi-device synchronization. Designed for pure acoustic immersion, it delivers studio-grade playback with ultra-low latency, zero third-party telemetry, and instant pairing across devices.

> 🚨 **Note:** This repository serves as the official Release Hub for downloading compiled binaries (`.exe`). The core source code is maintained in a private repository to protect proprietary sync logic and security enclaves.

---

## ✨ Key Features

* 🎨 **Glassmorphic Mini Player**: A fully frameless, transparent, draggable OS-level mini player for Desktop, and seamless Picture-in-Picture (PiP) for Web.
* 🔒 **Zero-Login Ecosystem**: Hardware-locked access using 256-bit signatures. No passwords required.
* 📡 **STAR Sync (Host/Guest)**: Real-time multi-device playback synchronization. Guests connect via secure pairing links or QR codes.
* 🌗 **Adaptive Themes**: Flawless Light & Dark mode support with a custom 5-tier accent color palette (Host-controlled).
* 📴 **Offline Engine**: Download tracks directly for offline, high-quality 320kbps playback without internet.
* 🎙️ **Advanced Lyrics**: Real-time synchronized lyrics with multi-source fallback (LRCLIB, Jio, Manual).
* 🛡️ **Secret Admin Enclave**: Master passphrase-protected settings and governance dashboard.

## 📥 Download & Installation

### Windows Desktop (Official Installer)

1. Navigate to the official [**Releases**](../../releases) tab on GitHub.
2. Under the latest release (`v1.0.0`), locate the **Assets** section.
3. Download **`STAR.Music.Setup.1.0.0.exe`**.
4. Run the installer:
   * If prompted by Windows SmartScreen: Click **More info** → **Run anyway**.
   * The setup assistant will automatically install STAR Music and create a desktop shortcut.
5. Launch **STAR Music** and enjoy studio-grade, ad-free music!

## 🔒 Security & Privacy

STAR Music is designed from the ground up to respect user autonomy:
* **Zero Accounts / Zero Trackers**: No intrusive registration forms, email harvesting, or telemetry trackers.
* **Hardware-Bound Identity**: Cryptographic 256-bit device signatures keep your private audio sessions completely isolated.
* **Local-First Audio Engine**: Offline music stays on your local machine in high-speed, secure IndexedDB storage.
